# Evaluation datasets

RepoScope separates generated benchmark fixtures from future human-labelled repository snapshots.

## `benchmark/cases.jsonl`

The initial reproducible benchmark contains:

- 24 synthetic repository families across six representative language labels;
- one deliberately good, medium, and bad report per family;
- 12 adversarial reports using fabricated paths, mismatched quotes, and verbose professional wording.

Every row records its construction label and contains a self-contained manifest/report pair. The file
is generated by `scripts/generate_benchmark.py`; do not hand-edit generated rows.

## Scope limitation

Synthetic data is suitable for testing deterministic path, line, quote, schema, and threshold logic.
It is not evidence of agreement with human experts or performance on live Hy3 outputs. Real snapshot
collection, licensing notes, annotator instructions, and blinded annotations will live in separate
folders so these evidence levels cannot be confused.
