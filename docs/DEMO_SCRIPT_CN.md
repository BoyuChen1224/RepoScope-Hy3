# RepoScope Hy3 演示脚本（建议 90 秒）

仓库中的 GIF 是 10.3 秒无声流程预览。正式提交视频可按以下脚本录制，控制在 90 秒内。

| 时间 | 画面 | 旁白要点 |
| --- | --- | --- |
| 0-12 秒 | 首页与采用目标 | 真实问题不是“仓库写了什么”，而是“我们能否相信采用结论” |
| 12-28 秒 | 输入公开仓库 | 限制来源、固定 commit、删除临时克隆，避免证据漂移 |
| 28-44 秒 | 证据清单 | README、许可证、测试和 CI 是证据，不直接等于成熟或安全 |
| 44-62 秒 | Hy3 报告 | 关键结论给出文件、行号和原文；证据不足进入 unknowns |
| 62-78 秒 | 评估维度 | 展示证据覆盖、引用有效、原文落地、不确定性、可执行性与 Schema |
| 78-88 秒 | 对抗样本 | 伪造引用即使专业冗长，也会触发硬门槛并封顶 59 |
| 88-90 秒 | 结果页 | 84 个样本与完整逐条结果均已开源，可一键复现 |

正式录制前必须用有效 TokenHub Key 完成至少一个真实 Hy3 案例；如果仍未完成，视频中应
明确说“当前展示为固定演示样本”，不能暗示为真实 API 返回。
